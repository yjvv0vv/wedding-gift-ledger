축의금 장부 웹앱 배포 안내

포함 파일
- index.html: 웹앱 본체
- manifest.webmanifest: 홈 화면 앱 정보
- sw.js: 처음 방문 후 앱 파일을 캐시해 오프라인 실행을 돕는 서비스 워커
- icons/: 홈 화면 아이콘

GitHub Pages에 배포하는 간단한 방법
1. GitHub 계정을 만들거나 로그인합니다.
2. 새 저장소(repository)를 만듭니다. 예: wedding-gift-ledger
3. 이 ZIP의 압축을 풀고, 파일과 icons 폴더를 저장소 최상위에 업로드합니다.
4. 저장소 Settings > Pages로 이동합니다.
5. Build and deployment에서 Deploy from a branch를 고르고, Branch는 main, 폴더는 /(root)로 선택한 뒤 Save합니다.
6. 몇 분 뒤 Pages 화면에 표시된 주소를 엽니다. 주소는 보통 https://계정이름.github.io/저장소이름/ 형태입니다.
7. 아이폰 Safari에서 그 주소를 엽니다. 공유 버튼 > 홈 화면에 추가 > (표시된다면) 웹 앱으로 열기 > 추가를 누릅니다.

저장 관련 중요 안내
- 이 버전은 localStorage를 사용하므로 기록은 그 기기의 해당 브라우저에만 저장됩니다.
- 자동으로 클라우드에 동기화되지 않으며, 다른 기기에서 기록을 볼 수 없습니다.
- Safari 웹사이트 데이터 삭제, 브라우저/기기 문제 등으로 기록이 사라질 수 있으므로 축의금 기록을 시작하기 전에 백업 파일 저장/복원 기능을 시험하고, 정기적으로 JSON 백업을 안전한 장소에 보관하세요.
- GitHub Pages 저장소가 공개 저장소라면, 장부 데이터는 GitHub에 올라가지 않더라도 공개 URL 자체를 누구나 열 수 있습니다. 민감한 개인정보를 많이 기록하지 말고, 실제 사용 전에 본인만 아는 별도 보안 및 백업 방식을 고려하세요.
- 이 ZIP은 웹앱 파일 패키지이며, 자동 배포된 공개 주소를 포함하지 않습니다. 직접 호스팅해야 아이폰에서 접속할 주소가 생깁니다.
